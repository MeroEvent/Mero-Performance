# Mero-Performance

An enterprise-grade Employee Attendance & Workforce Management System built with **Next.js 15**, **React 19**, **Supabase**, and **Tailwind CSS**.

---

## 🚀 Features

- 🕒 **Real-Time Attendance Tracking**: Geofencing (GPS), IP network verification, and device fingerprinting.
- 📑 **Official Academic & Enterprise Attendance Reports**: Clean, verified attendance transcripts with high-resolution 1-click PDF downloads.
- 👥 **Employee Directory & Profile Management**: Comprehensive role-based access control (Admin, Manager, Staff).
- 🏢 **Department & Shift Scheduling**: Flexible work shifts, grace period thresholds, and automated time calculations.
- 🌴 **Leave & Holiday Management**: Leave request workflows, status approvals, and company holiday calendars.
- 📊 **Executive Analytics Dashboard**: Live metrics for on-time rates, tardiness, worked hours, and employee logs.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router & Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Backend & Database**: [Supabase](https://supabase.com/) (PostgreSQL & Supabase Auth)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🏁 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/MeroEvent/Mero-Performance.git
cd Mero-Performance
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env.local` file in the root directory:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
